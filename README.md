# ThemeInterfacer XPOSED MODE

# how to install

1. install substratum 1022 apk and themeinterfacer xposed mode apk
2. install both them to device
3. put code ```<int name="current_theme_mode" value="18723789" />``` to projekt.substratum_preferences.xml placed on /data/user/0/projekt.substratum/shared_prefs/projekt.substratum_preferences.xml (requires root or saf patch to substratum apk)
4. open substratum and check interfacer status
5. enjoy
